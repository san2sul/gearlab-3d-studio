사용자 지정 기어박스 외곽 편집기 · v0.3 베타

아래 도면을 클릭해 꼭짓점을 추가하거나, 좌표(mm)를 직접 편집하세요. 입력한 다각형 안에 현재 두 평기어를 배치할 수 있는지 탐색합니다. 파란색은 내부 공간, 초록색은 배치 가능, 주황색은 배치 실패를 뜻합니다.

검증 범위: 평면상 두 평기어의 외접원과 외곽 간 여유를 확인합니다. 축·베어링·벽체 강도·치형 간섭 및 실제 3D 출력 적합성은 아직 검증하지 않습니다.

사용자 형상 기반 3D 케이스 · v0.4 베타

1-1 · 공통 설계 데이터 검증 · v1.6

기어 치수·케이스 외곽·두께·축 좌표를 읽기 전용 설계 스냅샷으로 통합하고 일관성을 검사합니다.

일체형 2축 관통 덮개 · v1.5

다각형 외곽에 축 구멍 2개를 직접 생성합니다. 메시 검사 통과 시에만 STL을 내보냅니다. 축 정렬·체결·실물 출력 검증은 별도입니다.

1단계 · 형상 엔진 검증 · v1.4

목표: 관통 구멍이 있는 일체형 케이스·덮개. 현재는 분리형 타일을 검증 중이며 일체형 부품은 아직 구현되지 않았습니다.

관통 구멍 덮개 시험 제작 · v1.3

직사각형 케이스에서 축 1·2의 구멍이 뚫린 좌·우 덮개 타일을 각각 생성합니다. 두 타일은 분리형이며 하나의 통합 덮개가 아닙니다. 각 타일의 모서리 연결 검사를 통과해야 저장됩니다.

STL 메시 구조 검사 · v1.2

생성된 기어박스 케이스·덮개·축 장착판의 삼각형 모서리 연결 상태를 분석합니다. 모서리 2회 공유 여부와 방향 일치를 검사하지만, 자기 교차 및 실제 슬라이서 수리는 검증하지 않습니다.

관통 구멍이 있는 축 장착판 · v1.1

기어 중심에 정렬되는 독립형 원형 장착판 2개를 생성합니다. 축 구멍은 STL 형상에 실제로 관통됩니다. 케이스 바닥과 덮개 전체에 구멍을 뚫는 기능은 아직 아닙니다.

케이스·덮개 정렬 가공 도면 · v1.0

현재 기어 중심을 기준으로 바닥판과 덮개에 같은 좌표의 축 관통 구멍을 표시한 1:1 SVG 도면을 생성합니다. STL 자체에 구멍을 뚫지는 않습니다.

체결용 원통 스페이서 · v0.9

나사 관통 구멍이 있는 분리형 스페이서를 생성합니다. 케이스 및 덮개에 나사 구멍을 자동으로 뚫지는 않습니다.

분리형 덮개 · v0.8

사용자 지정 외곽과 동일한 윤곽의 독립형 평판 덮개를 생성합니다. 축 관통 구멍·나사 체결부·케이스와의 맞춤 공차는 아직 포함되지 않습니다.

축 지지 부싱 · v0.7

축 구멍이 관통된 독립형 원통 부싱 2개를 STL로 생성합니다. 케이스 바닥과 결합되는 구조는 아직 아닙니다.

외곽 다각형으로 바닥판과 벽체를 생성합니다. 복잡한 오목 다각형에서는 벽체가 겹치거나 외곽 밖으로 돌출될 수 있으며, 베어링·축 구멍·덮개는 미구현입니다. 입체 기어는 시각화용이며 기어 치형의 실제 맞물림·간섭은 검증되지 않았습니다. 축 위치 SVG는 가공 참고 도면입니다. STL은 시제품이며 출력 전 메시 검사가 필요합니다.
